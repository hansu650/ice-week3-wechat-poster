# 每人一个 SVG、一个 PR

1. 登录自己的 GitHub，Fork https://github.com/hansu650/ice-week3-wechat-poster 到自己账号。
2. 按自己的 [提示词](prompts/ALL_PROMPTS_CN.md) 生成 reference_chart.svg。
3. 在自己的 Fork 的 w3/contributions/本人名字/ 下上传这个 SVG。
4. 点 Contribute → Open pull request，目标为 hansu650/ice-week3-wechat-poster 的 main。
5. 把 PR 链接交给 Team Leader Tian Qin，他来检查和合并。

仓库是公开的，不需要提前加入协作者。只交一张参考 SVG，不写报告、不交其他文件。最终海报继续使用 Tian Qin 已审核的图。

[GitHub 官方 Fork 说明](https://docs.github.com/en/pull-requests/how-tos/work-with-forks/fork-a-repo) · [从 Fork 创建 PR](https://docs.github.com/en/pull-requests/how-tos/create-pull-requests/creating-a-pull-request-from-a-fork)
