## Workflow

1. Tian Qin invites the three members; each accepts using their own GitHub account.
2. Send each person only their [text prompt](prompts/ALL_PROMPTS_CN.md).
3. Each checks the original source and generates candidate SVG/PNG figures with analysis in their own contributions directory.
4. Each commits their own files to main and sends Tian Qin the commit link.
5. Tian Qin records concrete feedback in [leader_review.md](reviews/leader_review.md), checks revisions and selects the accepted final images for [figures/](figures/README.md).
6. Full-poster integration follows Tian Qin’s explicit approval of the small figures. Real photos are added after the actual activity.
