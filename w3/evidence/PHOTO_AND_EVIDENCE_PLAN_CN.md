# 真实拍摄与 GitHub 证据计划

**当前未拍摄，大海报照片位先留空。下列是计划，不是完成记录。**

## 一次 15–20 分钟的真实小组审图

带电脑、小图审核册和三篇论文的相关表格。四个人实际核对数据、讨论修改，拍下过程中自然发生的动作。

| 照片 | 实际活动 | 怎么拍 | 证明什么 |
|---|---|---|---|
| 01 小组审图 | Tian Qin 主持，成员逐一说明自己的模块 | 横拍 4:3 或 16:9；定时器拍到人、桌面和图 | 共同讨论、组长组织 |
| 02 数据核对 | 一人指原文表格，另一人核对图与笔记 | 拍手、屏幕和核对纸的近景 | 来源核验 |
| 03 反馈后修改 | Tian Qin 与成员比较修改前后版本 | 屏幕显示实际 SVG 或 commit 差异 | 评审与改进 |
| 04 成品合影（之后） | 大海报完成后四人展示真实成品 | 成员与成品清晰入镜 | 最终产出 |

有人不愿露脸时可拍手、笔记与屏幕，在图注中如实列参与者。出镜者同意后再使用；避开私聊、账号凭据和无关个人信息。
后来补拍的是哪天的复查，就写哪天的复查。

## 拍摄细节

- 后置相机正常拍摄，不用人像虚化。
- 从侧前方采光，避开屏幕反光。
- 每个场景拍 2–3 张，选清楚的一张；保留原始照片。
- 命名：YYYY-MM-DD_01_group-review.jpg，填实际日期。
- 大海报预留 3 个横向照片位；成品合影也可放作品集。
- 不用网图或生成图替代小组活动现场照。

## GitHub 留什么

当前由 Tian Qin 统一上传，不要求成员 Fork 或 PR。保存实际 commit 链接、分析脚本与输出、来源检查和真正发生的修改。记录制作与核对的实际参与者，不能仅凭上传账号推断成员分工。真实小组照片先留在本地，确认使用后再添加。

## 完成后填写的图注

Photo: “On [actual date], [members present] reviewed [specific figure/source] and agreed to [actual change].”

GitHub: “I checked [source/table], revised [file], and submitted commit [link]. After [actual feedback], I changed [specific detail].”

Leadership: “As Team Leader, Tian Qin reviewed [commit link], requested [actual correction], and integrated [change] on [actual date].”

方括号填真实发生的内容；未完成就继续保留待做标记。
